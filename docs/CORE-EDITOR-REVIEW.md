# Core editor review and shared UI ownership

This round addresses reproducible editing, numerical and host-integration defects in the generic package. Storage, transport, authorization, directories and application workflow remain host-owned. Regression tests run without a consumer checkout or backend.

## Corrected behavior

| Area                     | Defect and correction                                                                                                                                                                                                                                                                                                                   | Regression coverage                                                                                     |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Native bulk edits        | Delete/Backspace previously preflighted each cell against the same stale workbook, leaving only the first change accepted. Batches now publish atomically, restore accepted state after rejection, and retain review previews.                                                                                                          | `e2e/core-engine.spec.ts`, `src/engine/worksheet-data.test.ts`                                          |
| Native input fidelity    | Finishing an unchanged native edit converted boolean/canonical inputs to text. No-op edits now preserve the original value and canonical metadata. Capture excludes padded viewport blanks and preserves geometry.                                                                                                                      | `e2e/native-cell-editing.spec.ts`, `src/engine/worksheet-data.test.ts`                                  |
| Resource limits          | Native batch capture could allocate oversized sparse data before model validation. Bounds now apply before allocation, and failures use the same rollback/error path.                                                                                                                                                                   | `src/engine/worksheet-data.test.ts`                                                                     |
| Durability and history   | A second flush could acknowledge a newer uncommitted draft with an older receipt. Flushes now commit first and queue by requested revision. History commits native/formula drafts, awaits configured durability, and stays closed on failure or newer edits. Permission loss cancels barriers; manual saves cancel redundant autosaves. | `src/editor/editor-lifecycle.test.tsx`, `src/editor/use-editor.test.ts`                                 |
| Semantic operations      | Workbook-title changes had no command operation, and writes beyond identified extents omitted line introductions. Invertible metadata operations and appended-ID line insertions now accompany cell patches. Ordinary writes and paste use the host ID factory.                                                                         | `src/editor/review-panels.test.tsx`, `src/model/host-model.test.ts`, `src/model/clipboard.test.ts`      |
| Host panels              | History buttons ignored external undo availability. Properties could retain an old accepted title and allowed rejected changes to escape through UI events. Controls now use current capabilities, preserve local title drafts and report rejections.                                                                                   | `src/editor/review-panels.test.tsx`                                                                     |
| Search and clipboard     | Previous skipped the final match, rejected navigation still advanced the counter, and pending calculations copied blanks. Navigation and replacement availability now follow accepted matches; unavailable clipboard values fall back to authored inputs.                                                                               | `src/editor/editor-search.test.tsx`, `e2e/host-integration.spec.ts`                                     |
| Calculation lifecycle    | Changing a title, visual style or equivalent controlled snapshot unnecessarily cancelled/repeated calculation. Passes now follow authored calculation identity; re-enabling calculation still starts a fresh pass.                                                                                                                      | `src/editor/use-calculation.test.ts`                                                                    |
| Quantities and summaries | Scalar-only function arguments accepted units, compatible ATAN2 coordinates were rejected, and selection statistics stripped dimensions. Guards and aggregates now use quantity-aware rules and preserve provenance.                                                                                                                    | `src/calculation/dimensional-arguments.test.ts`, `summary.test.ts`, `src/editor/editor-search.test.tsx` |
| Calendar                 | Month shifting reused DATE's year shorthand for internal year 1899 and crossed the supported upper boundary to find a month's last day. Internal calendar shifts now stay in the valid serial domain.                                                                                                                                   | `src/calculation/calendar-boundaries.test.ts`                                                           |
| Excel                    | Direct rich host calls exported HTML in frozen cached results even when the expression had been converted to plain text. Cache projection and long-text fallback now use the declared bounded text policy; additional standard conversion aliases are supported.                                                                        | `src/excel/excel.test.ts`, `src/calculation/dimensional-arguments.test.ts`                              |

Lazy initial engine adoption could also steal focus and shift the Add worksheet button during its first press, cancelling the command. Initial adoption now preserves chrome focus, and reference presentation reserves the viewport before the engine arrives. Browser regressions cover delayed adoption and pending formula formatting with undo.

## Shared controls already available

| Control responsibility                         | Generic owner                                                                          | Editor responsibility                                                         |
| ---------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Notices, history status and calculation errors | ui-components Banner and InlineError, now used directly                                | Message content, severity, expiry and recovery actions                        |
| Search and replacement controls                | ui-components FindBar                                                                  | Match discovery, cell navigation, authored-only replacement and availability  |
| Formula entry and completions                  | ui-components FormulaBar, CodeEditor and CompletionList                                | Formula grammar, reference picking, protected drafts and function descriptors |
| Font, color and formatting controls            | ui-components NumberField, ColorField, ColorSwatchButton/Picker, menus and popovers    | Spreadsheet formatting commands, presets and physical-unit interpretation     |
| Toolbar, worksheet and panel layout            | ui-components ToolbarRow, Tabs, DockPanel, ZoomControl                                 | Workbook state, worksheet operations and engine viewport                      |
| Conversations and actors                       | ui-components CommentThread, CommentComposer, ReactionBar, Attribution and AvatarGroup | Range anchors, suggestion baselines and host identities                       |
| Navigation confirmation                        | ui-components UnsavedChangesGuard, composed by the host when needed                    | Public draft/save/flush handle; no duplicate navigation service               |

No additional ui-components dependency or API is required for these corrections. Spreadsheet arithmetic, workbook operations, grid geometry and collaboration binding are not generic control responsibilities. No transport or application-specific component is added to either package.

## Decisions retained for a later round

- Multi-header resizing currently applies a shared delta, retaining differences between original widths/heights. Normalizing every selected line to the dragged line's resulting size changes interaction semantics and needs a product choice.
- Saved history currently opens through a context-menu View action. The shared VersionHistory control supports direct selection and richer compare/restore actions; adopting it requires choosing the desired activation behavior rather than silently changing the current contract.
- A preset/custom-color toolbar composite could be shared if multiple editors need the same composition. The current implementation already uses the public color primitives. Keep the existing composition until a common API and consumers justify a new public component.

## Validation

Run the repository's complete check before commit. The check consists of lint, formatting, typecheck, all unit tests, package build, built-consumer smoke tests and browser suites. If the npm entrypoint is unavailable, run the installed check tools directly without changing package-manager trust, and report that distinction. Do not equate a blocked launcher with passing checks.
