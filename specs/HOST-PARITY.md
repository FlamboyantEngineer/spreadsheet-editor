## Application integration responsibilities

These are requirements on Host's application and services, not missing generic editor implementations:

- **SE-DS storage and SE-CO transport:** durable room state, Yjs/awareness, authorization, route navigation, server leases, generations, autosave storage, cross-room atomic transactions and conflict resolution. Supply `value`, `onChange`, `sessionKey`, `readOnly`, `permissions`, `collaborators`, `onPresenceChange` and `onSave(snapshot, context)`. A host must validate mutations server-side; advisory UI locks are not a concurrency protocol.
- **SE-VR routing/storage:** fetch immutable snapshots and workflow metadata, authorize access, retain route timestamps, remember pane preferences, and load the latest version before clearing historical state. Supply `history`, `historical` and host panel content. The package uses no fixed routes or browser storage.
- **SE-CR platform panes and workflows:** application title/breadcrumbs, Work Item Properties, AI, Workflow, export-control marking, related artifacts, organizational preferences, user/group directories, typed mention resolution/notifications and platform rich comment-composer integrations. Hosts can replace the Properties, History and Comments panes and add AI/Workflow panes. Built-in posts remain plain text; there is no automatic group expansion or notification service.
- **External formulas and pinned contexts:** WORKITEM, WORKITEM.FIELD, WORKITEM.FIELD.LABEL, WORKITEM.FIELD.PROMPT, DOCUMENT.FIELD and USER.NAME/EMAIL/FIRSTNAME/LASTNAME are supplied by `FormulaHost`, with authorization and immutable pinning performed by the host. Resolved named/call operands are captured in calculation context for export. The package does not copy Host's service dispatcher or resolve platform URLs.
- **SE-XL production import/export workflows:** upload/batch/source provenance, folder selection, prepared-result persistence, bounded compute pools, immutable stored-version lookup, route permissions, attachment headers, readiness polling and production download orchestration belong to the application. `onImportXlsx` owns file selection/preview/confirmation; `onExportXlsx` receives the current authored snapshot and matching existing calculation result. A production host should export its authorized stored version through `/excel`. The labs routes are a local harness, not production API routes.

## Intentional standalone differences

The user's exact-number requirement takes precedence over Host's finite decimal baseline. Exact rational values never round during arithmetic, including `1E-25`, `1-1E-25`, and `1/3*3`. Non-rational functions return explicitly marked configurable high-precision approximations. General display defaults to 32 significant digits (configurable), rather than Host's 15. Budget errors retain this package's version-1 `#LIMIT!` token instead of renaming it to `#CALC!`.

Engineering quantities use the standalone rational kernel and a documented curated SI conversion registry; this package does not embed the complete platform SDK constants/quantity catalog or its revision-pinning services. Hosts may resolve additional constants through `FormulaHost`. Non-terminating exact values that Excel cannot represent round-trip export as fraction text; terminating decimals retain their full decimal text when native Excel numbers would lose digits.

Chrome is configurable: the full preset also retains a dedicated Suggestions pane and menu commands for pane access; minimal and embedded hosts need not expose that full desktop arrangement. The built-in plain-text composer and standalone conversation data are not Host's shared organizational comment service. Consumer-specific rich mentions, platform panel arrangement and transport behavior are integrated through host adapters rather than silently emulated.

## Intentional visual updates

The reusable editor now uses the public library ToolbarRow, FormulaBar/CodeEditor and Tabs. Embedded action triggers are icon-only. Inline worksheet rename replaces the legacy modal; worksheet ellipsis navigation and the formula field action buttons are removed. Grid zoom changes presentation geometry and text inside a fixed viewport, keeping borders at one CSS pixel. These changes supersede legacy visual descriptions while retaining the calculation, review, permissions and persistence contracts above.
