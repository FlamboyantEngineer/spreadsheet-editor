# Host compatibility

The spreadsheet editor is a generic package. Application storage, authorization, collaboration transport, directories, workflows and durable history stay behind public host callbacks. No application-specific renderer, route, storage schema or feature flag belongs to the library.

Calculation extent excludes purely visual and annotation anchors, so those changes cannot invalidate host results. Explicit minimum dimensions, defined geometry, merges and identities still affect whole-line ranges. Editor extent separately includes all anchored metadata to prevent clipping or data loss.

## Numerical contract

The native engine keeps exact rational arithmetic: `1/3*3` is exactly 1, tiny scientific values survive cancellation, display defaults to 32 significant digits, and non-rational operations use an isolated 80-digit approximation context. Resource limits produce `#LIMIT!`. The [intentional-difference manifest](NUMERIC-INTENTIONAL-DIFFERENCES.json) records precise comparisons with a finite-decimal reference. There are no function-family exemptions.

Hosts may instead publish authoritative or immutable captured results through external calculation mode. Missing or pending values remain unavailable without invoking the native calculator. Loading historical results causes no writes or refresh calls. Hosts retain their own numerical policy and persistence schema.

## Host responsibilities

A host may connect semantic operations to its existing shared document, supply its own local undo manager, enforce permissions and generation state, publish safe cell presentation, and await an established durability receipt from `onFlush`. It owns provider lifetime, navigation barriers, immutable history and rich-content sanitation. A failed flush retains the current session and edits until retry or explicit host abandonment.

Formula descriptors advertise host capabilities without authorizing execution. Excel capabilities explicitly identify permitted host functions and captured-text policy; exports use stored operands without live resolution. Unknown functions return `#NAME?` in native calculation.

[HOST-INTEGRATION.md](HOST-INTEGRATION.md) owns the public contracts. [Source provenance](../NOTICE.md) records upstream revisions and paths. Normal CI uses portable fixtures and requires no application checkout or backend.
